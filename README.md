# Plataforma Multi-Tenant SST & PESV - PostgreSQL

Sistema relacional desarrollado en PostgreSQL para la gestión integral de Seguridad y Salud en el Trabajo (SST) y Planes Estratégicos de Seguridad Vial (PESV) bajo un modelo de arquitectura multi-tenant.

## Despliegue con Docker Compose
1. Clonar el repositorio.
2. Copiar `.env.example` a `.env` y configurar credenciales.
3. Ejecutar `docker compose up -d`.
4. Acceder a pgAdmin en `http://localhost:8081`.
